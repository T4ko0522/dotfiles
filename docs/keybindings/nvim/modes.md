# モードの基礎

Vim は **モードエディタ** です。今どのモードにいるかによって、同じキー (例: `i`) の意味が違います。これが Vim 最大の特徴であり、慣れると圧倒的に速く編集できる理由でもあります。

ステータスラインの左端 (modicator が色を変えている部分) を見れば現在のモードが分かります。

## 5つの基本モード

```
                              i, I, a, A, o, O
                          ┌──────────────────────┐
                          ▼                      │
            ┌─────────────────────┐      ┌──────────────┐
            │   Normal モード      │      │ Insert モード │
            │   (起動時)           │◀────│   (文字入力)   │
            └─────────────────────┘ Esc  └──────────────┘
              │  ▲           │  ▲
        v,V,  │  │ Esc       │  │ Esc
        Ctrl+v│  │           │  │
              ▼  │           ▼  │
            ┌──────────┐  ┌──────────────┐
            │  Visual  │  │   Command    │
            │  (選択)   │  │  ( : で開始)  │
            └──────────┘  └──────────────┘
```

| モード | 何をするモードか | 入り方 | 抜け方 |
| --- | --- | --- | --- |
| **Normal** | 移動・編集コマンドを発行 (`d`, `y`, `p`, など) | 起動時。他モードから `Esc` | — |
| **Insert** | 文字を入力 | `i`, `a`, `o`, `I`, `A`, `O` | `Esc` |
| **Visual** | 範囲選択 (文字単位) | `v` | `Esc` |
| **Visual Line** | 範囲選択 (行単位) | `V` (Shift+v) | `Esc` |
| **Visual Block** | 範囲選択 (矩形) | `Ctrl+v` | `Esc` |
| **Command** | `:w` など Ex コマンド入力 | `:` | `Enter` 実行 / `Esc` 中止 |

## モード切り替えで覚えること

### Normal → Insert (文字を打ち始める)

| キー | 位置 |
| --- | --- |
| `i` | カーソル位置に挿入 |
| `a` | カーソルの **次** から挿入 |
| `I` | 行頭 (空白を除く) に挿入 |
| `A` | 行末に挿入 |
| `o` | 下に1行追加して挿入 |
| `O` | 上に1行追加して挿入 |

### Insert → Normal (編集に戻る)

- `Esc` (一番素直)
- `Ctrl+[` (Esc 同等。ホームポジション維持できる)
- `Ctrl+c` (近い動作、ただし autocmd `InsertLeave` を発火させない場合あり)

### Normal → Visual (選択を始める)

| キー | 選択単位 |
| --- | --- |
| `v` | 文字単位 |
| `V` | 行単位 |
| `Ctrl+v` | 矩形単位 (列をまたいで一括編集) |

選択中は `hjkl` などで範囲を広げ、`d`/`y`/`c` 等で操作します。

### Normal → Command

- `:` でコマンドラインに入る (画面下のフローティングは noice.nvim が描画)
- `/` で前方検索、`?` で後方検索

## カーソル/行番号の色変化 (modicator)

このリポジトリでは `modicator.nvim` を導入しているので、**現在の行番号の色がモードで変わります**。慣れるまでは行番号の色を見てモードを判別すると安心です。

## 「とりあえずノーマルに戻る」癖をつける

Vim を始めたばかりの人がやるべき一番大事な癖は、**作業の合間に Esc を押してノーマルに戻ること**。 ノーマルから始めることで、移動・編集コマンドが安全に発行できます。
