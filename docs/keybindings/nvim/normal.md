# Normal モード

Vim 操作の 8 割はここ。覚えるべきキーは多いですが、**移動 + 操作 + 範囲** の組み合わせという文法で理解すると一気に楽になります。

## Vim の文法 (operator + motion)

```
[count] [operator] [motion]
   3        d         w     ← 「3 単語削除」
```

例:
- `dw` → 単語1つ削除 (`d` = delete, `w` = next word)
- `3dw` → 単語3つ削除
- `dd` → 行を1行削除
- `y$` → カーソルから行末までヤンク (`y` = yank, `$` = 行末)
- `ci"` → ダブルクォート内側を変更 (`c` = change, `i"` = inside `"`)

このパターンが理解できれば、未知のコマンドも組み合わせで推測できます。

## 移動

### 1文字〜行内

| キー | 動作 |
| --- | --- |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 |
| `w` / `W` | 次の単語の頭 (`W` は記号を区切りとしない) |
| `b` / `B` | 前の単語の頭 |
| `e` / `E` | 単語の末尾 |
| `0` | 行頭 (本当の先頭) |
| `^` | 行頭 (空白を除く先頭) |
| `$` | 行末 |
| `f<char>` | カーソルから右で `<char>` の位置へ |
| `F<char>` | カーソルから左で `<char>` の位置へ |
| `t<char>` / `T<char>` | `f`/`F` の **1 文字手前** で止まる |
| `;,` | `f`/`F`/`t`/`T` の逆方向リピート (`,` がリーダー化したため再割当) |

### 行間〜画面

| キー | 動作 |
| --- | --- |
| `gg` | ファイルの先頭 |
| `G` | ファイルの末尾 |
| `5G` または `:5` | 5 行目へ |
| `{` / `}` | 段落単位で上下 |
| `(` / `)` | 文単位で上下 |
| `H` / `M` / `L` | 画面の High / Middle / Low |
| `Ctrl+d` / `Ctrl+u` | 半画面 下 / 上 |
| `Ctrl+f` / `Ctrl+b` | 1 画面 進む / 戻る |
| `zz` → `z` | カーソル位置を **中央 → 上 → 下** に循環 (1秒以内に `z` を続けて押す) |

### ジャンプ系

| キー | 動作 |
| --- | --- |
| `%` | 対応する括弧へジャンプ |
| `Ctrl+o` | 直前のジャンプ位置に戻る |
| `Ctrl+i` | `Ctrl+o` の逆 (Tab と区別済) |
| `gd` | 定義へジャンプ (LSP) |
| `gD` | 宣言へジャンプ (LSP) |
| `gf` | カーソル下のファイルパスを開く |
| `gh` | カーソル下のリンク (URL/ファイル) を開く |
| `gx` | URL またはカーソル下の AWS ARN をブラウザで開く |
| `<leader>gR` | カーソル下を `owner/repo` と見なして GitHub を開く |

## 検索

| キー | 動作 |
| --- | --- |
| `/foo` | 前方検索 |
| `?foo` | 後方検索 |
| `n` / `N` | 次のヒット / 前のヒット |
| `*` | カーソル下の単語を前方検索 |
| `#` | **カスタム**: カーソル下の単語を `:%s/word//g` に流し込む (置換テンプレ) |

> ノーマルの素の `#` (前方検索) は失われていますが、代替として `*` → `N` で同等のことができます。

## 編集 (operator)

| operator | 意味 |
| --- | --- |
| `d` | 削除 (delete) |
| `c` | 変更 (change。削除してインサートへ) |
| `y` | ヤンク (yank。コピー) |
| `p` / `P` | プット (paste。`p`=後、`P`=前) — **本リポジトリでは `+` レジスタ (システムクリップボード) から貼り付け** |
| `>` / `<` | インデント増減 |
| `=` | 自動整形 |
| `gu` / `gU` | 小文字化 / 大文字化 |

### よく使う組み合わせ

| コマンド | 動作 |
| --- | --- |
| `x` | 1 文字削除 |
| `dd` | 1 行削除 |
| `D` または `d$` | 行末まで削除 |
| `dw` | 単語削除 |
| `dap` | 段落削除 (a paragraph) |
| `yy` | 1 行ヤンク |
| `yiw` | 単語ヤンク (inside word) |
| `ci"` | `"..."` の中身を変更 |
| `ca(` | `(...)` を中身ごと変更 |
| `cit` | HTML/XML タグの中身を変更 |
| `>>` / `<<` | 行のインデント増減 |
| `==` | 行の自動整形 |
| `+` | カスタム: カーソル下の数値をインクリメント (旧 `<C-a>`) |
| `-` | カスタム: 数値をデクリメント (旧 `<C-x>`) |

> `mini-surround` を入れているので **`saiw"`** (Surround a inner word with `"`) や **`srd("` (置換)、**`sd"`** (削除) が使えます。詳しくは [plugins.md](plugins.md)。

## ヤンク・プットの仕組み (本リポジトリの特殊設定)

LazyVim デフォルトでは `clipboard=unnamedplus` でヤンクと OS クリップボードが常に同期しますが、本リポジトリでは:

- **`y` でヤンクしたとき** だけ `+` レジスタ (OS クリップボード) に同期
- **`d`/`x` などの削除** は OS クリップボードを汚さない
- **`p` / `P` は明示的に `"+` (OS クリップボード) から貼り付け**

つまり「ブラウザでコピーしたものを `p` で貼れる」「Vim で削除したテキストがクリップボードを上書きしない」状態です。

## ウィンドウ/タブ操作

| キー | 動作 |
| --- | --- |
| `Tab` | 次のタブ |
| `Shift+Tab` | 前のタブ |
| `ss` | 水平分割 |
| `sv` | 垂直分割 |
| `sh` / `sj` / `sk` / `sl` | 分割間移動 (左/下/上/右) |

## 診断 (LSP)

| キー | 動作 |
| --- | --- |
| `Ctrl+j` | 次の診断 (エラー/警告) へ |
| `]d` / `[d` | 次/前の診断 (LazyVim 標準) |

| `<leader>ca` | コードアクション |
| `<leader>cr` | リネーム (inc-rename で対話的) |
