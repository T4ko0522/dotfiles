# Visual モード

範囲選択するモード。3 種類あって、それぞれ選択単位が違います。

| モード | 開始キー | 選択単位 | 用途 |
| --- | --- | --- | --- |
| Visual | `v` | 文字単位 | 単語の一部、文の途中まで |
| Visual Line | `V` (Shift+v) | 行単位 | コード行のコピー、一括コメント |
| Visual Block | `Ctrl+v` | 矩形 (列) | 縦に揃えて入力 / 削除 |

## 共通の操作 (選択後)

| キー | 動作 |
| --- | --- |
| `d` | 削除 |
| `y` | ヤンク (このリポジトリでは `+` レジスタに自動同期) |
| `c` | 変更 (削除して Insert へ) |
| `p` / `P` | 選択範囲を貼り付けで置換 |
| `>` / `<` | インデント増減 |
| `=` | 自動整形 |
| `gu` / `gU` | 小文字化 / 大文字化 |
| `o` | 選択の **始点と終点を入れ替え** (片方を伸ばし足りないとき) |
| `Esc` | 選択解除して Normal に戻る |
| `gv` | **直前の Visual 選択を再現** (Normal モードで) |

## Visual (`v`) で覚えるべきこと

- 文字単位で選択する基本モード
- 移動キー (`w`, `e`, `f<char>` 等) で範囲を伸ばす
- `vi"` のような **テキストオブジェクト** が強力

### テキストオブジェクト (Vim 最強の機能のひとつ)

| 表記 | 意味 |
| --- | --- |
| `iw` | 単語の中身 (inside word) |
| `aw` | 単語 + 周囲の空白 (around word) |
| `i"` `i'` `i\`` | クォートの中身 |
| `i(` `i[` `i{` | 括弧の中身 |
| `it` | HTML/XML タグの中身 |
| `ip` | 段落の中身 |
| `is` | 文の中身 |

例:

- `vi"` → ダブルクォートの中身を選択
- `va(` → 丸括弧ごと選択
- `vip` → 段落を選択

## Visual Line (`V`)

- 行単位で選択
- 上下移動 (`j`, `k`) で行を増やす
- そのまま `>` でブロックインデント、`gc` でコメントトグル (LazyVim 標準)

```
V       ← この行から
jjj     ← 3 行下まで選択
>       ← 一括インデント
```

## Visual Block (`Ctrl+v`)

矩形選択。複数行に同じ文字を同時に入れたいときに使います。

| 操作 | 動作 |
| --- | --- |
| `Ctrl+v` で選択 → `I<text><Esc>` | 選択範囲の **左端** に `<text>` を一括挿入 |
| `Ctrl+v` で選択 → `A<text><Esc>` | 選択範囲の **右端** に `<text>` を一括挿入 |
| `Ctrl+v` で選択 → `c<text><Esc>` | 選択範囲を `<text>` で **一括置換** |
| `Ctrl+v` で選択 → `d` | 列を削除 |

**例 — 行頭にコメント記号を一括追加:**

```
Ctrl+v      ← Visual Block 開始
jjjj        ← 4 行下まで選択
I// <Esc>   ← 左端に "// " を挿入
```

## 本リポジトリのカスタム (Visual で動くキー)

| キー | 動作 |
| --- | --- |
| `;,` | `,` の代替 (`f`/`F`/`t`/`T` 逆方向リピート) |
| `p` / `P` | `+` レジスタ (システムクリップボード) から貼り付け |
| `<leader>as` | 選択範囲を **Claude Code に送信** (claude-code.nvim) |
| `<leader>mc` | Markdown ファイルで、選択範囲の **文字数を表示** (記法除去後) |
| `<leader>y` | yazi をその位置で起動 (visual も可) |

## クリップボードと選択の関係

- Visual で `y` した内容は OS クリップボードにも自動同期 (本リポジトリ設定。`autocmds.lua` の `TextYankPost` 参照)
- 削除 (`d`, `x`) はクリップボードに同期しません

## ちょっと変わった使い方

### 同じ単語を全部選択して一括変更

1. カーソルを単語に合わせて `*` → Vim が単語を検索
2. `:%s//新しい単語/g` で全置換
3. または **`gn`** (次の検索ヒットを Visual 選択) + `c<text><Esc>` → `.` 連打で「次のヒットも同じ変更」

### Visual 中に範囲を縦に揃える

矩形選択中に `Ctrl+a` で連番を自動付与する技 (`g Ctrl+a` で `g<Ctrl+a>`) もあります — 例えば 4 行選択して全部 `1.` と打って `g Ctrl+a` すると `1. 2. 3. 4.` になります。
