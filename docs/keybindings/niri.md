# niri キーバインド

設定ファイル: [`nix-configs/home/niri-keybind.nix`](../../nix-configs/home/niri-keybind.nix)

`Win` は niri 設定上の `Mod` キーです。

## 起動・終了

| キー | 操作 |
| --- | --- |
| `Win+Enter` | WezTerm を起動 |
| `Win+T` | WezTerm を起動 |
| `Alt+Space` | Vicinae を開く |
| `Win+V` | クリップボード履歴を開く |
| `Win+Q` | ウィンドウを閉じる |
| `Win+Shift+E` | niri を終了 |
| `Win+Shift+P` | モニターの電源を切る |

## フォーカス移動

| キー | 操作 |
| --- | --- |
| `Win+H` | 左の列へフォーカス |
| `Win+J` | 下のウィンドウへフォーカス |
| `Win+K` | 上のウィンドウへフォーカス |
| `Win+L` | 右の列へフォーカス |

## ウィンドウ・列の移動

| キー | 操作 |
| --- | --- |
| `Win+←` | 列を左へ移動 |
| `Win+↓` | ウィンドウを下へ移動 |
| `Win+↑` | ウィンドウを上へ移動 |
| `Win+→` | 列を右へ移動 |
| `Win+Ctrl+←` | 列を左へ移動 |
| `Win+Ctrl+↓` | ウィンドウを下へ移動 |
| `Win+Ctrl+↑` | ウィンドウを上へ移動 |
| `Win+Ctrl+→` | 列を右へ移動 |
| `Win+Ctrl+J` | ウィンドウを下へ移動 |
| `Win+Ctrl+K` | ウィンドウを上へ移動 |

## モニター間移動

| キー | 操作 |
| --- | --- |
| `Win+Ctrl+H` | ウィンドウを左のモニターへ移動 |
| `Win+Ctrl+L` | ウィンドウを右のモニターへ移動 |

## ワークスペース

| キー | 操作 |
| --- | --- |
| `Win+PageDown` | 下のワークスペースへフォーカス |
| `Win+PageUp` | 上のワークスペースへフォーカス |
| `Win+Ctrl+PageDown` | 列を下のワークスペースへ移動 |
| `Win+Ctrl+PageUp` | 列を上のワークスペースへ移動 |
| `Win+1` - `Win+9` | 指定したワークスペースへフォーカス |

## レイアウト

| キー | 操作 |
| --- | --- |
| `Win+R` | プリセット列幅を切り替え |
| `Win+F` | 列を最大化 |
| `Win+Shift+F` | フルスクリーン切り替え |
| `Win+C` | 列を中央へ配置 |
| `Win+-` | 列幅を 10% 縮小 |
| `Win+=` | 列幅を 10% 拡大 |

## スクリーンショット

| キー | 操作 |
| --- | --- |
| `Print` | スクリーンショット |
| `Ctrl+Print` | 画面のスクリーンショット |
| `Alt+Print` | ウィンドウのスクリーンショット |

## 音量

| キー | 操作 |
| --- | --- |
| `XF86AudioRaiseVolume` | 音量を上げる |
| `XF86AudioLowerVolume` | 音量を下げる |
| `XF86AudioMute` | ミュート切り替え |
| `XF86AudioMicMute` | マイクミュート切り替え |

## ヘルプ

| キー | 操作 |
| --- | --- |
