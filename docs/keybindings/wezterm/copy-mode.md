# コピーモード — `copy_mode` key table

定義箇所: [`dot_config/shared/wezterm/keymaps.lua`](../../../dot_config/shared/wezterm/keymaps.lua) の `key_tables.copy_mode`

`Leader → c` で起動。vim 風のキーバインドで移動・選択・コピー・検索を行う。

## カーソル移動

| キー | 動作 |
| --- | --- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右へ 1 セル |
| `w` | 単語の先頭へ前進 |
| `b` | 単語の先頭へ後退 |
| `e` | 単語の末尾へ前進 |
| `^` | 行頭（インデント後の最初の文字）へ |
| `$` | 行末（最後の文字）へ |
| `0` | 行の左端（カラム 0）へ |

## ビューポート / スクロールバック移動

| キー | 動作 |
| --- | --- |
| `H` | ビューポート上端へ |
| `M` | ビューポート中央へ |
| `L` | ビューポート下端へ |
| `g` | スクロールバック先頭へ |
| `G` | スクロールバック末尾へ |
| `Alt+b` | 1 ページ上へ |
| `Alt+f` | 1 ページ下へ |
| `Alt+u` | 半ページ上へ |
| `Alt+d` | 半ページ下へ |

## 文字ジャンプ

| キー | 動作 |
| --- | --- |
| `f` | 指定文字の上へ前方ジャンプ |
| `F` | 指定文字の上へ後方ジャンプ |
| `t` | 指定文字の手前へ前方ジャンプ |
| `T` | 指定文字の手前へ後方ジャンプ |
| `;` | 直前のジャンプを再実行 |

## 検索（スクロールバック内）

`/` または `?` で検索文字列入力に入る。`Enter` で確定すると `copy_mode` に戻り、`n` / `N` で巡回できる。検索入力中は WezTerm 既定の `search_mode` キーが有効（`Ctrl+r` で match タイプ巡回、`Backspace`、`Esc` キャンセル等）。

| キー | 動作 |
| --- | --- |
| `/` | case-sensitive 検索を開始 |
| `?` | case-insensitive 検索を開始 |
| `n` | 次のマッチへ |
| `N` | 前のマッチへ |

## 選択モード

| キー | 動作 |
| --- | --- |
| `v` | セル選択モード |
| `Alt+v` | ブロック（矩形）選択モード |
| `V` | 行選択モード |
| `o` | 選択範囲の反対側へカーソルを移動（縦） |
| `O` | 選択範囲の反対側へカーソルを移動（横） |

## コピー / 終了

| キー | 動作 |
| --- | --- |
| `y` | クリップボードへコピーしてモード終了 |
| `Enter` | クリップボード + プライマリ選択にコピーしてモード終了 |
| `Esc` | コピーせずに終了 |
| `q` | コピーせずに終了 |
| `Alt+c` | コピーせずに終了 |
