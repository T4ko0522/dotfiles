# タブ — `tab_ops` key table

定義箇所: [`.config/shared/wezterm/keymaps.lua`](../../../.config/shared/wezterm/keymaps.lua) の `key_tables.tab_ops`

`Alt+a` でトグル起動。`one_shot = false` のため操作後も継続。再度 `Alt+a` か `Esc` で終了。

## キー一覧

| キー | 動作 |
| --- | --- |
| `Tab` | 次のタブへ |
| `Shift+Tab` | 前のタブへ |
| `t` | 新しいタブを作成（現在のドメイン） |
| `w` | タブを閉じる（確認あり） |
| `[` | タブを左へ移動 |
| `]` | タブを右へ移動 |
| `1` 〜 `8` | 指定番号のタブへ移動 |
| `9` | 末尾のタブへ移動 |
| `Alt+a` | モード終了 |
| `Esc` | モード終了 |
